# 稿件

只在对象被判定为稿件时读取。每次只启用获批完成条件点名的参考项。

## 准入

1. **M-A1 体裁**：写明技术、业务、研究、科普、新闻、演讲、宣传、文学与创意，或用户给出的更细类型。
2. **M-A2 判据来源**：列出投稿须知、约稿、brief、平台规则或用户明确要求。
3. **M-A3 特殊属性**：若要启用新闻、商业广告或其它合规项，写明适用的平台、法域或规则；未确认则不启用。
4. **M-A4 退出**：只有文采、感染力、“像人写”等主观要求，且提炼不出客观判据时，按主 Skill 第 1 步停止。

**完成标准**：体裁与拟用规则已记录，特殊属性已确认或未启用；需要停止时已经停止。

## 可定位检查

只有被获批完成条件点名的项才执行：

1. **M-C1 声称**：客观声称与已给材料是否对应；找不到则标未证实。
2. **M-C2 引用**：引用、数据、他人表述是否有可核出处。
3. **M-C3 术语**：同一术语、产品名、人物名在全文是否一致。
4. **M-C4 数字**：同一数字、单位、日期在全文是否一致。
5. **M-C5 已选要求**：只核已获批 brief、平台或法域规则明确要求的字数、结构、归因、广告声称、操作顺序、披露项等。

文学与创意稿件可把已获批 brief 中的人物、视角、时间线、长度或禁用项映射到 M-C5；没有 brief 时不自造审美标准。

**完成标准**：每个已启用项都有「通过 / 候选（含位置与原文）/ 不适用（含理由）」；主观偏好未进入候选。

## 停止 / 不可核验

- **M-S1** 材料不足以核对声称时，标不可核验，不编出处。
- **M-S2** 未选平台、法域或 house style 时，其规则不约束对象。
- **M-S3** 不能仅凭稿面承诺事实正确、发表或传播效果。

**完成标准**：不可核验项已标明；未选规则未进入候选。

## 禁止输出

- **M-F1** 不把文采、感染力、“像人写”写成真问题。
- **M-F2** 不承诺发表、采信或传播效果。
- **M-F3** 不从零代写，也不作没有逐项定位的整篇重写。

**完成标准**：候选与改法不含 M-F1～M-F3。
