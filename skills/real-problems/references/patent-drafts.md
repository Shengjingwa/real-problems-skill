# 专利草稿

只在对象被判定为专利草稿时读取。审查已有草稿中的可定位文本问题，不作专利法律结论。

## 准入

1. **P-A1 司法辖区**：写明中国国家申请、PCT 国际阶段、指定国国家阶段或其它辖区。
2. **P-A2 专利类型**：写明发明、实用新型、外观设计或适用辖区的对应类型。
3. **P-A3 申请阶段**：写明申请前草稿、初审/形式审查、实质审查答复、无效/诉讼或其它阶段。
4. **P-A4 拟用规则**：列出用户选定的官方规则、版本和适用条款；中国与 PCT 规则分开。
5. **P-A5 材料**：列出说明书、权利要求书、摘要、附图、既有申请文本、通知书、对比文件等本轮核对材料。
6. **P-A6 退出**：P-A1～P-A3 缺一项时先补问；仍无法确认则停止，不默认套用中国或 PCT 规则。

**完成标准**：辖区、类型、阶段、拟用规则与材料均已记录，或已按 P-A6 停止；未选规则未启用。

## 可定位检查

只有被获批完成条件点名、且适用于 P-A1～P-A4 的项才执行：

1. **P-C1 文件与栏目**：拟用规则要求的文件、栏目是否出现。
2. **P-C2 编号与引用**：权利要求、段落、附图等编号和引用关系是否满足已选规则。
3. **P-C3 术语一致**：权利要求、说明书、摘要中的同一技术特征是否使用一致名称。
4. **P-C4 图文一致**：附图标记与正文是否双向对应，同一部件是否使用同一标记。
5. **P-C5 说明书支持**：权利要求记载的技术特征能否在说明书中找到对应文字。
6. **P-C6 可观察文本缺口**：是否只写目标而没有技术手段，关键手段是否只有含糊词，问题、方案、效果是否互相矛盾。只报原文可见风险，不判断法律后果。
7. **P-C7 已选形式要求**：摘要长度、名称、从属关系等只按 P-A4 已选规则逐项检查，不缓存或混用其它辖区阈值。

外观设计只执行其已选规则适用的文件、图片/照片与简要说明检查，不套用发明或实用新型的权利要求、说明书检查。

**完成标准**：每个已启用项都有「通过 / 候选（含位置、原文或标记）/ 不适用（含理由）」；未选辖区、类型、阶段或规则的项目未进入候选。

## 停止 / 不可核验

- **P-S1** 没有适用规则时，只能执行用户已批准的内部一致性项；不能给形式或法律合规结论。
- **P-S2** 对比文件可作核对材料，但不得据此输出新颖性、创造性、FTO 或侵权结论。
- **P-S3** 拟用规则没有明确当前阶段可修改范围时，只保留问题清单，不设计替换。
- **P-S4** “所属技术人员能否实现”“保护范围是否适当”不写成确定结论；只报 P-C5、P-C6 可见的文本风险。

**完成标准**：不可核验项已标明并跳过；修改范围不明时未进入改对象。

## 禁止输出

- **P-F1** 将会授权、不会授权或授权概率。
- **P-F2** 新颖性、创造性是否成立，或 FTO、侵权与不侵权结论。
- **P-F3** 把中国、PCT 或其它辖区规则混用。
- **P-F4** 从零起草，或没有逐项定位地重写整份权利要求书、说明书、技术交底书或答复。

**完成标准**：候选、清单与改法不含 P-F1～P-F4；任何替换都有已确认阶段与规则依据。
