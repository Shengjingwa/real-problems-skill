# 报告

只在对象被判定为报告时读取。每次只启用获批完成条件点名的参考项。

## 准入

1. **R-A1 文类**：写明报告类型。
2. **R-A2 判据来源**：列出用户 brief、组织模板或用户选定的官方/平台规则及版本。
3. **R-A3 材料**：列出用于核对的模板、证据、图表和数据。
4. **R-A4 退出**：文类、判据都无法确定，且没有可客观检验项时，按主 Skill 第 1 步停止。

**完成标准**：R-A1～R-A3 已记录，或已按 R-A4 停止；未选规则未启用。

## 可定位检查

只有被获批完成条件点名的项才执行：

1. **R-C1 栏目**：已选模板或规则要求的栏目是否出现。
2. **R-C2 出处**：正文中的客观声称能否在核对材料中找到出处。
3. **R-C3 证据对应**：正文与证据、图表中的数字、日期、名称是否一致。
4. **R-C4 内部一致**：同一术语、数字、时间在全文是否矛盾。
5. **R-C5 文类要求**：只核已选规则明确要求的其它项目。工程复盘、法定调查、研究报告不得互套栏目或责任语言。

**完成标准**：每个已启用项都有「通过 / 候选（含位置与原文）/ 不适用（含理由）」；未启用项未进入候选。

## 停止 / 不可核验

- **R-S1** 未选模板或规则时，不补造“通用报告栏目”。
- **R-S2** 根因、责任、影响数字在材料中无依据时，标不可核验，不编结论。
- **R-S3** 已撤回或本轮未选定的规则不得作为检查项。

**完成标准**：不可核验项已标明；未用未选或失效规则继续检查。

## 禁止输出

- **R-F1** 不承诺发表、采信或调查结论正确。
- **R-F2** 不输出跨文类的“必须追责”或“必须无指责”。
- **R-F3** 不从零代写，也不作没有逐项定位的整篇重写。

**完成标准**：候选与改法不含 R-F1～R-F3。
