# real-problems

一个专为 AI 编码助手（Agent）设计的规范与规则治理工具（Skill）：针对已保存在本地磁盘上的 **AI 提示词/工作流**、**工程架构规范** 或 **运维与业务操作手册（SOP）**，通过引入项目实际代码事实进行多角度并行审查，找出真正影响执行的硬伤（真问题），并在人工审核确认（闸门机制）后精准修改文件。

---

## 核心特性

- **只抓真问题**：拒绝模棱两可的主观润色，只处理“能指到具体位置、且不改必定导致规则失效、与项目实际脱节或执行死锁”的硬缺陷。
- **项目现实深度对照（调研闸门）**：支持深入项目代码库、真实配置与执行环境，核实文档声称的命令/路径/接口字段是否真实存在，或对标成熟规范寻找遗漏的防御分支，拒绝闭门造车。
- **支持交互式判据提炼**：若文档未显式写明完成条件，第 1 步由 Agent 提炼候选判据并由人工确认，兼顾规范性与通用性。
- **人工闸门把关**：在调研、确定真问题清单、确认最终改法等关键节点均需人工确认，绝不擅自破坏原有规则。
- **快照与精准修改**：修改前自动在系统临时目录备份快照，修改后严格比对 diff 并验证问题消除，不夹带任何方案外改动。

## 适用与不适用场景

### ✅ 适用对象（三大类别）

1. **AI 提示词、技能与工作流**
   - Agent Skill 技能定义文件（如 `SKILL.md`）
   - 系统提示词（System Prompt）、输出格式约束模板
   - 多 Agent 协作与状态转移路由、评测标准（Eval Rubrics）
2. **系统架构与工程规范**
   - Agent 指引与项目规则（`AGENTS.md`、`.cursorrules`）
   - 架构决策记录（ADR）
   - 团队代码规范、MR 合入清单、API 接口数据契约
3. **运维、安全与业务操作手册**
   - 应急止血预案（Runbook）、数据库割接/迁移 SOP、灾备演练说明
   - 生产环境发布清单、环境搭建手册、权限审计规范
   - 带有明确验收准则（AC / Given-When-Then）的产品与测试规格

### ❌ 不适用场景
- **代码运行时报错排查**：请使用常规排查工具或排查类 skill（如 `diagnosing-bugs`）。
- **产品与业务需求讨论**：请使用需求评审工具（如 `grilling`）。
- **从零新建 Skill**：请使用 `create-skill`。
- **代码架构重构与拆模块**：请使用代码设计类工具（如 `codebase-design`）。

## 安装与使用

### 1. 安装

在命令行中执行：

```bash
npx skills add Shengjingwa/real-problems-skill
```

> **注意**：
> - 本仓库内的 `skills/real-problems/` 即为 Skill 本体，目录名必须保持为 `real-problems`（与 `SKILL.md` 中的 `name` 一致）。
> - 运行过程中产生的记录笔记会自动保存在本仓库的 `docs/` 目录下（已在 `.gitignore` 中忽略，不提交到 git）。

### 2. 使用

在 Cursor 中新建对话，输入斜杠命令即可调用：

```text
/real-problems
```
